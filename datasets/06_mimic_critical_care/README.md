# MIMIC-IV 3.1 & ED Critical Care Database

Full institutional cohort located at: `datasets/mimiciv/3.1/` (hosp, icu, ed).
- **Hospital Module (`hosp/`)**: Admissions, Patients, Labevents (5M+ rows), Prescriptions, Diagnoses ICD.
- **ICU Module (`icu/`)**: ICU Stays (73,181 stays), Chartevents, Inputevents, Procedureevents.
